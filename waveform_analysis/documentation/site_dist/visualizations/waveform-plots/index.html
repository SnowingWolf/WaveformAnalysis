波形图

使用 Plotly 浏览多通道波形，或检查 peak 通道波形与求和波形。

整体介绍

Context 驱动的波形访问均显式指定 run_id。

波形图函数

Plotly 适合交互浏览；批量 peak 检查应复用 plotter。

plot_waveforms

python
(waveforms: numpy.ndarray | list[numpy.ndarray], hits: numpy.ndarray | None = None, event_index: int = 0, channels: list[waveform_analysis.core.hardware.channel.HardwareChannel | tuple[int, int] | str] | None = None, title: str = 'Waveform Viewer')

创建原始波形与可选 hit 标注的交互图。

参数

数据表
参数说明
waveforms波形数组列表、二维数组或带 board/channel 的 structured array。
hits可选 hit structured array，用于标注。
event_index要显示的事件索引。
channels待显示通道；使用 (board, channel)、"board:channel" 或 HardwareChannel。
title图标题。

返回值

交互式 Plotly figure；Plotly 缺失时返回 None。

示例

python
figure = plot_waveforms(waveforms, event_index=0, channels=["0:3"])

plot_peak_channels_with_sum

python
(peak_id, *, context, run_id: str, pad: int = 30, group_by: str = 'board_channel')

绘制单个 peak 的逐通道与求和波形。

参数

数据表
参数说明
peak_id目标 peak 的整数 ID。
context已配置插件和存储的 Context。
run_id显式指定要访问、执行或诊断的运行 ID。
padhit 窗口两端扩展的采样点数。
group_by按 channel 或 board_channel 分组。

返回值

(figure, axes)；没有 peak 数据时均为 None。

使用注意

  • 批量检查多个 peak 时应使用 create_peak_plotter()。

示例

python
fig, axes = plot_peak_channels_with_sum(919, context=ctx, run_id="run_001")

create_peak_plotter

python
(context, run_id: str)

创建绑定 Context 和 run_id 的可复用 peak 绘图函数。

参数

数据表
参数说明
context已配置插件和存储的 Context。
run_id显式指定要访问、执行或诊断的运行 ID。

返回值

预加载数据的 plot_func(peak_id, pad, group_by)。

使用注意

  • 返回函数会持有预加载数组，使用完毕后释放引用。

示例

python
plot_peak = create_peak_plotter(ctx, "run_001")
fig, axes = plot_peak(919)
