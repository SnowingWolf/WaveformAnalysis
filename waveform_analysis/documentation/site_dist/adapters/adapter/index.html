Context/DAQ 适配器

DAQ 适配器

DAQ 适配器层把不同数字化仪（CAEN VX2730/V1725 等）的文件格式、目录布局、时间戳单位封装为可注册的 DAQAdapter，上层插件链路只面向统一的 records/wave_pool/st_waveforms 抽象。

整体介绍

适配器层是原始 DAQ 文件与框架内部数据结构之间的统一边界。它把"哪种数字化仪、哪种文件格式、哪种目录布局、哪种时间戳单位"这些硬件相关差异封装在一组可注册、可组合的适配器里，使上层插件链路只需面向统一的 records/wave_pool/st_waveforms 抽象编程。

推荐使用流程

先列出并检查内置 adapter，再将名称写入 Context 的全局 daq_adapter 配置；注册插件后，通过 Context 检查 adapter 元数据和目标插件的已解析配置。显式插件配置优先于 adapter 推断，adapter 推断优先于插件默认值。

list_adapters

python
() -> list[str]

列出当前进程已注册的 adapter 名称；导入 waveform_analysis.acquisition.formats 后内置 vx2730 与 v1725 可用。

返回值

已注册 adapter 名称列表。

示例

python
from waveform_analysis import Context
from waveform_analysis.plugins import profiles
from waveform_analysis.acquisition.formats import get_adapter, list_adapters

run_id = "run_001"
adapter_name = "vx2730"
assert adapter_name in list_adapters()

# 在请求插件产物前检查 DAQ 文件与通道发现结果。
adapter = get_adapter(adapter_name)
channels = adapter.scan_run("DAQ", run_id)

ctx = Context(config={"data_root": "DAQ", "daq_adapter": adapter_name})
ctx.register(*profiles.cpu_default())

# adapter 元数据与解析后的插件配置均可直接检查。
print(ctx.get_adapter_info())
ctx.show_resolved_config("records")
records = ctx.get_data(run_id, "records")

Context.get_adapter_info

python
(self, adapter_name: 'str | None' = None) -> 'AdapterInfo | None'

读取当前 Context 选中的 adapter 的采样率、时间戳单位、原生时间戳语义与采样间隔。

参数

数据表
参数说明
adapter_name已注册的 DAQ adapter 名称；未提供时从 Context.config['daq_adapter'] 读取。

返回值

AdapterInfo；未配置或名称未注册时返回 None。

使用注意

  • daq_adapter 应使用已注册 adapter 的名称，而不是 DAQAdapter 实例。
  • 在执行处理前先确认 sampling_rate_hz、timestamp_unit 与 raw_timestamp_mode 是否符合原始数据。

示例

python
info = ctx.get_adapter_info()
if info is None:
    raise RuntimeError("daq_adapter 未配置或未注册")
print(info.name, info.sampling_rate_hz, info.timestamp_unit, info.dt_ns)

Context.get_resolved_config

python
(self, plugin: 'Plugin | str', adapter_name: 'str | None' = None) -> 'ResolvedConfig'

获取指定插件的最终配置，用于区分显式值、adapter 推断值与插件默认值。

参数

数据表
参数说明
plugin已注册插件实例或其 provides 名称。
adapter_name已注册的 DAQ adapter 名称；未提供时从 Context.config['daq_adapter'] 读取。

返回值

包含配置来源的 ResolvedConfig。

使用注意

  • 传入字符串时，该插件必须已通过 Context.register() 注册。

示例

python
resolved = ctx.get_resolved_config("records")
print(resolved.summary(verbose=True))

核心抽象

TimestampUnit/RawTimestampMode 定义时间戳单位与语义；ColumnMapping 映射 CSV 列索引；FormatSpec 完整描述一种 DAQ 数据格式；DirectoryLayout 定义目录结构与文件匹配模式；FormatReader 为格式读取器抽象基类。

FormatSpec

python
(name: str, version: str = '1.0', columns: waveform_analysis.utils.formats.base.ColumnMapping = <factory>, timestamp_unit: waveform_analysis.utils.formats.base.TimestampUnit = <TimestampUnit.PICOSECONDS: 'ps'>, raw_timestamp_mode: waveform_analysis.utils.formats.base.RawTimestampMode = <RawTimestampMode.UNIT: 'unit'>, file_pattern: str = '*CH*.CSV', header_rows_first_file: int = 2, header_rows_other_files: int = 0, delimiter: str = ';', sampling_rate_hz: float | None = None, metadata: dict[str, typing.Any] = <factory>) -> None

完整 DAQ 数据格式规范：列映射、时间戳单位、分隔符、文件模式、头部行数、采样率、元数据。

参数

数据表
参数说明
name适配器或格式规范的名称。
version格式规范版本号。
columnsCSV 列映射配置（ColumnMapping）。
timestamp_unit原生时间戳的物理单位（TimestampUnit）。
raw_timestamp_mode原生时间戳语义（RawTimestampMode）。

    timestamp_unit=TimestampUnit.NANOSECONDS,

)

完整适配器

DAQAdapter 组合 FormatReader 与 DirectoryLayout，提供 scan_run/load_channel/load_all_channels/load_channel_generator/extract_and_convert/normalize_timestamp_to_ps/get_file_epoch 等统一接口。

注册表与发现

格式注册表管理 FormatReader 与 FormatSpec 的映射；适配器注册表管理 DAQAdapter 实例。utils/formats/__init__.py 在导入时自动注册内置格式 vx2730_csv 与 v1725_bin。

register_adapter

python
(adapter: waveform_analysis.utils.formats.adapter.DAQAdapter) -> None

注册完整的 DAQ 适配器实例到全局注册表；注册后通过其名称写入 Context 的 daq_adapter 配置。

参数

数据表
参数说明
adapter要注册的完整 DAQAdapter 实例。

返回值

无返回值。

使用注意

  • 自定义 adapter 应在创建 Context 和请求插件数据前注册。
  • 注册表是进程内状态；新的 Python 进程需要再次导入或注册自定义 adapter。

示例

python
from waveform_analysis import Context
from waveform_analysis.acquisition.formats import (
    ColumnMapping, DAQAdapter, DirectoryLayout, FormatSpec,
    GenericCSVReader, TimestampUnit, register_adapter,
)

spec = FormatSpec(
    name="my_csv",
    columns=ColumnMapping(timestamp=3),
    timestamp_unit=TimestampUnit.NANOSECONDS,
    delimiter=",",
    sampling_rate_hz=500e6,
)
layout = DirectoryLayout(
    name="my_layout", raw_subdir="data",
    file_glob_pattern="*.csv", channel_regex=r"channel(\d+)",
)
adapter = DAQAdapter("my_adapter", GenericCSVReader(spec), layout)
register_adapter(adapter)

ctx = Context(config={"data_root": "DAQ", "daq_adapter": "my_adapter"})

from waveform_analysis.acquisition.formats import get_adapter

内置适配器

vx2730: CAEN VX2730 数字化仪（CSV，分号分隔，500 MHz，ps）；v1725: CAEN V1725 DAW_DEMO（二进制 .bin，sample index → ps，Numba 加速解析）。

get_adapter_vx2730

python

返回值

VX2730 DAQAdapter 实例。

示例

python
from waveform_analysis.acquisition.formats import get_adapter
adapter = get_adapter("vx2730")
channel_files = adapter.scan_run("DAQ", "run_001")
