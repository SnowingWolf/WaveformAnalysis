处理链概览

WaveformAnalysis 采用插件驱动的 DAG 处理链，将原始 DAQ 波形转化为物理事件与分析结果。

raw_filesScan the data directory and group raw CSV files by channel number.
recordsBuild records (event index table) from the shared internal records bundle.
hit_thresholdThreshold-only hit detector with THRESHOLD_HIT_DTYPE output.
peakletsBuild lightweight cross-channel peaklets from hit_merged intervals.
peaksBuild final peaks table from peaklets and waveform-derived features.
eventsComplete event reconstruction from S1-S2 pairs and position

下一步：运行一个最小示例

几行代码构建并运行处理链。

python
from waveform_analysis import Context
from waveform_analysis.plugins import profiles

ctx = Context(config={
    "data_root": "DAQ",
    "daq_adapter": "vx2730",
})
ctx.register(*profiles.cpu_default())
result = ctx.get_data("run_001", "records")
print(result)
