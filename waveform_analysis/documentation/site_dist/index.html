处理链概览

完整依赖图

沿当前处理链，查看波形、时间区间和配对关系如何逐步形成。以下为算法示意，非实测、非比例。

  1. 01

    采集与记录

    解析采集文件，以时间和板卡/通道定位记录，再通过索引读取波形池。

    raw_filesrecordswave_pool
  2. 02

    阈值检测

    相对基线、按信号极性判定过阈区间；每段区间形成一个 hit。

    hit_threshold
  3. 03

    同通道合并

    按间隔与总宽限制合并同通道、同 dt 的 hit。默认合并间隔为 0。

    hit_merged
  4. 04

    跨通道聚合

    按时间窗口组织不同通道的 hit 区间，汇总成员、起止时间与通道数。

    peaklet_componentspeaklets
  5. 05

    波形与分类

    重建并求和成员波形，提取面积和时序特征，再按配置分类；默认未设置分类规则。

    peaklet_waveformspeakspeak_classification
  6. 06

    配对与事件

    在漂移时间窗内生成候选，再标记 selected。默认按 center_time 配对；选中项结合位置形成事件。

    s1_s2_pair_candidatess1_s2_pairsevents

跨通道聚合阶段只组织区间；波形求和在后续进行。配对默认 center_time 为 50% 面积时刻，未选候选仍保留，且不保证全局一对一。中间产物与分支请查看完整依赖图。

运行一个最小示例

注册默认插件，通过 run_id 和目标产物读取数据。

python
from waveform_analysis import Context
from waveform_analysis.plugins import profiles

ctx = Context(config={
    "data_root": "DAQ",
    "daq_adapter": "vx2730",
})
ctx.register(*profiles.cpu_default())
result = ctx.get_data("run_001", "records")
print(result)
