Accessor/RecordsView

RecordsView

按稳定 record_id 访问 records 与 wave_pool，并统一完成窗口、批量填充和信号极性处理。

整体介绍

RecordsView 将正式插件产物 records 与 wave_pool 组合成只读访问层。推荐通过 records_view(ctx, run_id) 构造；所有公开波形接口使用 record_id，不使用 records 数组行号。

数据模型与不变量

数据表
项目约束
排序records 按 (timestamp, pid, board, channel) 全局排序。
record_id排序后从 0 开始连续编号，是公开波形访问的稳定标识。
波形范围每条记录满足 0 <= wave_offset 且 wave_offset + event_length <= len(wave_pool)。
波形归属wave_pool[wave_offset:wave_offset + event_length] 是该记录的完整原始波形。
一对一对齐

排序、分片合并或重新物化 wave_pool 时必须同步重写 wave_offset；波形池的数组下标不能被当作 record_id。

公开访问与派生波形池

records_view 按稳定 record_id 回切 wave_offset:event_length，signals(...) 再依据 records 的 polarity 统一信号方向。

滤波波形

wave_pool_filtered 与同一 records 保持布局对齐；通过 records_view(ctx, run_id, wave_pool_name="wave_pool_filtered") 选择它，不会改变 record 元数据或索引关系。

python
# 选择滤波后的派生波形池；与同一 records 布局对齐
from waveform_analysis.core.data import records_view

rv = records_view(
    ctx, "run_001", wave_pool_name="wave_pool_filtered"
)

# 批量读取前若干条 record 的滤波波形
record_ids = rv.records["record_id"][:32]
waves, valid = rv.waves(record_ids, pad_to=256, mask=True)

共享构建与缓存

  • 内部 bundle 仅在当前 Context 会话复用；正式 records 与 wave_pool 可由存储后端持久化。
  • 请求任一正式产物后再请求另一个，会复用同一 bundle，避免重复读取原始文件。
  • 构建语义、读取器行为或影响输出内容的 tracked 配置变化必须升级两个插件的版本，以失效旧 lineage。

    plugin_name="records",

当 records 与 wave_pool 同时注册时，wave_pool 通过 _resolve_bundle_config_plugin 采用 records 的动态依赖和配置。

V1725 限制

V1725 使用专用二进制读取与分片合并路径，明确拒绝 input_source="st_waveforms"。

组件与公开边界

数据表
组件职责下游边界
RecordsBundle(records, wave_pool)一次构建期间共享成对结果内部缓存对象，不是下游依赖
RecordsBundleRef临时 memmap 分片引用与超大数据构建能力不是常规插件输出契约
RecordsPlugin发布元数据侧正式 records 产物
WavePoolPlugin发布采样侧正式 wave_pool 产物
records_view(ctx, run_id)组合正式产物进行 record 访问推荐波形访问接口

下游插件应声明 records、wave_pool 或与 records 对齐的派生产物；不得依赖 RecordsBundle 或 _records_bundle-* 内部缓存键。

构造与数据源

从显式 run 的正式插件产物创建视图，或直接组合已加载的 NumPy 数组。

records_view

python
(source: Any, run_id: str, records_name: str = 'records', wave_pool_name: str = 'wave_pool') -> waveform_analysis.core.data.records_view.RecordsView

从 Context-like source 加载 records 与指定 wave pool，并创建 RecordsView。

参数

数据表
参数说明
source提供正式插件产物的 Context 或兼容对象。
run_id显式指定要访问、执行或诊断的运行 ID。
records_namerecords 元数据插件产物名称。
wave_pool_name波形池插件产物名称；可指定 wave_pool_filtered。

返回值

RecordsView 实例。

使用注意

  • 必须显式传入 run_id；缺少正式 records 或 wave_pool 产物时直接报错。
  • 读取滤波波形时设置 wave_pool_name="wave_pool_filtered"。

示例

python
# 从 Context-like source 构造视图；默认读取原始 wave_pool
from waveform_analysis.core.data import records_view

rv = records_view(ctx, "run_001")

# 切换为滤波波形池（与同一 records 对齐）
filtered = records_view(
    ctx, "run_001", wave_pool_name="wave_pool_filtered"
)

RecordsView

python
(records: numpy.ndarray, wave_pool: numpy.ndarray)

直接组合 records structured array 与其引用的一维 wave_pool。

参数

数据表
参数说明
records包含 record_id、wave_offset、event_length 等字段的 structured array。
wave_pool由 records 的 wave_offset 和 event_length 引用的一维波形池。

返回值

只读的 RecordsView 实例。

使用注意

  • record_id 必须唯一，且所有 wave_offset/event_length 范围必须位于 wave_pool 内。

波形访问

按 record_id 读取单条或批量原始波形，并可限定采样窗口。

waves

python
(self, record_ids: int | collections.abc.Iterable[int] | numpy.ndarray, pad_to: int | None = None, mask: bool = False, baseline_correct: bool = False, dtype: numpy.dtype | None = None, sample_start: int = 0, sample_end: int | None = None) -> numpy.ndarray | tuple[numpy.ndarray, numpy.ndarray]

读取原始波形；批量访问时返回统一宽度的二维数组。

参数

数据表
参数说明
record_ids单个 record_id，或一组 record_id；不是 records 行号。
pad_to批量返回时统一填充到的采样点数。
mask批量返回时是否同时返回有效采样点掩码。
baseline_correct是否从原始波形中减去每条 record 的 baseline。
dtype可选输出 dtype；信号默认使用 float32。
sample_start窗口起始采样点，包含该位置。
sample_end窗口结束采样点，不包含该位置。

返回值

单条一维数组、批量二维数组；mask=True 时额外返回布尔掩码。

使用注意

  • pad_to 不能小于所选窗口中的最长波形。
  • baseline_correct=True 时默认输出 float32。

示例

python
# 取首条记录的 record_id（不能用 records 数组行号）
record_id = int(rv.records[0]["record_id"])
# 限定采样窗口读取单条原始波形
wave = rv.waves(record_id, sample_start=40, sample_end=120)
# 批量读取并对齐到统一长度；mask 标记有效行
waves, valid = rv.waves([record_id], pad_to=256, mask=True)

信号访问

减去 baseline，并依据 records.polarity 将脉冲统一为负极性。

signals

python
(self, record_ids: int | collections.abc.Iterable[int] | numpy.ndarray, pad_to: int | None = None, mask: bool = False, dtype: numpy.dtype | None = None, baseline: float | None = None, sample_start: int = 0, sample_end: int | None = None) -> numpy.ndarray | tuple[numpy.ndarray, numpy.ndarray]

读取 baseline 校正且极性归一化后的信号。

参数

数据表
参数说明
record_ids单个 record_id，或一组 record_id；不是 records 行号。
pad_to批量返回时统一填充到的采样点数。
mask批量返回时是否同时返回有效采样点掩码。
dtype可选输出 dtype；信号默认使用 float32。
baseline覆盖单条 signal 使用的 baseline；批量访问不支持覆盖。
sample_start窗口起始采样点，包含该位置。
sample_end窗口结束采样点，不包含该位置。

返回值

单条一维数组、批量二维数组；mask=True 时额外返回布尔掩码。

使用注意

  • baseline 覆盖仅支持单个 record_id。
  • records 不含 polarity 字段时保留 baseline 校正后的方向。

示例

python
# baseline 校正与极性归一化后的信号
signal = rv.signals(record_id, sample_start=40, sample_end=120)
# 批量读取信号，并对齐到统一长度
signals, valid = rv.signals([record_id], pad_to=256, mask=True)

时间查询

在已按 timestamp 排序的 records 中选择闭区间时间窗口。

query_time_window

python
(self, t_min: int | None = None, t_max: int | None = None) -> numpy.ndarray

返回 timestamp 位于 t_min 与 t_max 边界内的 records 子数组。

参数

数据表
参数说明
t_min最小 timestamp，包含边界；省略时从首条 record 开始。
t_max最大 timestamp，包含边界；省略时读取到末尾。

返回值

共享原 records 数据的 structured array 切片。

使用注意

  • 该方法只筛选 records 元数据；随后用返回行中的 record_id 读取波形。

示例

python
# 在 timestamp 排序的 records 中选择闭区间
subset = rv.query_time_window(t_min=0, t_max=1_000_000)
# 用返回行中的 record_id 读取波形
waves = rv.waves(subset["record_id"], mask=True)
