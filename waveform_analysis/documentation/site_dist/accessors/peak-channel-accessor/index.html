PeakChannelAccessor

按 peak 查询 threshold hits、硬件通道特征与波形，并提供常用对比绘图。

整体介绍

PeakChannelAccessor 面向单个 peak 的内部结构与通道级排查：可先查询 peak/merged 对应的 threshold hits，再以 (board, channel) 作为逻辑通道唯一键读取聚合特征和波形。

推荐使用方式是：

  1. 先用 get_hits() 或 get_merged_hits() 检查 threshold hit 的时间关系；
  2. 需要通道汇总时再读取轻量特征；
  3. 根据面积、高度或面积占比筛选通道；
  4. 仅对少量候选通道加载和检查波形。

这种设计避免了为全部 peak 和通道预先读取、切片体积较大的 wave_pool。

快速开始

python
from waveform_analysis.analysis import PeakChannelAccessor

accessor = PeakChannelAccessor(ctx, run_id="run_001", lazy_load=True)
channels = accessor.get_channels(peak_id=919)

字段来源与计算口径

通道必须使用 (board, channel) 作为唯一键。不能只使用 channel，因为不同采集板上可能存在编号相同的通道。

peaklet_channels 是唯一的通道聚合真源；缺失或字段不完整时 Accessor 会失败，不会退回到部分字段的字典。

聚合以 (peaklet_id, board, channel) 为分组键，且只使用 hit_merged_features.valid != 0 的有效组件。

数据表
字段含义计算口径
board采集板编号通道标识
channel板内通道编号通道标识
area通道面积同一 (peaklet_id, board, channel) 的有效组件 area 之和
height通道高度同一分组内有效组件 height 的最大值
n_hits通道 hit 数同一分组内有效组件 n_hits 之和
area_fraction通道面积占比area / peaklet_features.area；分母为 0 时为 0
merged_indices通道组件索引来自 peaklet_components 的全部 merged_index

代表组件与边界字段

width、rise_time、fall_time、center_time 与 record_id 来自高度最大的组件；merged_index 也指向该代表组件。

sample_start 与 sample_end 分别是所有组件的最小起点和最大终点；is_single_record 仅在全部组件均为单 record 时为真。

  • 面积、高度和 hit 数描述整个逻辑通道，时间字段只描述代表组件；
  • 波形字段与波形来源见「数据分层、加载与缓存」与「波形来源与语义」。

数据分层、加载与缓存

Accessor 将数据访问分为 hit 查询层、特征层和波形层，按需加载：

数据表
数据层主要依赖加载时机
hit 查询层peaklet_components、hit_merged_components、hit_threshold调用 get_hits() 或 get_merged_hits() 时
特征层peaklet_components、peaklet_channels、hit_merged、hit_merged_features查询通道特征时
波形层records、hit_threshold、hit_merged_components、wave_pool请求波形或绘图时

使用 lazy_load=True 时，纯 hit 查询不会读取 peaklet_channels、records 或 wave pool。调用 get_channels() 时只访问特征层，不读取通道波形；只有在 include_waveforms=True 或调用相关绘图方法时，Accessor 才会加载波形层。

这意味着可以先对大量 peak 执行轻量特征查询，再对少量候选加载波形。

设置 lazy_load=True 可以推迟首次特征层读取，直到真正执行查询，适合先创建多个访问器但不立即使用的场景。建议在同一个分析循环中复用同一个 PeakChannelAccessor，避免重复初始化和读取相同数据。

波形窗口按照 (merged_index, pad) 进行缓存，使用相同参数再次请求波形时可以复用已经提取的结果。

当内存紧张时，可以调用 clear_waveform_cache(release_wave_pool=True)，该操作会：

  • 清除已缓存的波形窗口；
  • 在 release_wave_pool=True 时释放波形层；
  • 保留 Accessor，使其仍可继续使用。

清理后再次请求波形时，Accessor 会重新加载所需的波形数据。

波形来源与语义

Accessor 中存在两类来源不同的波形。

数据表
波形类型获取方式数据来源
Peak 求和波形get_sum_waveform()peaklet_waveforms 生成的求和产物
通道或组件波形通道波形接口根据 hit 窗口和 pad 从 records + wave_pool 提取

两类波形的构建路径不同，因此不要求逐采样点完全一致。可能造成差异的因素包括：

  • 使用的时间网格不同；
  • wave_pool 中保存的是经过处理的波形；
  • 波形窗口及 pad 配置不同；
  • peak 求和波形与通道波形采用了不同的构建配置。
使用 `plot(view='sum-comparison')` 时

应将其理解为对两种波形构建结果的对照，而不是逐点相等性检验。

参数

数据表
参数说明
peak_id目标 peak 的整数 ID。

返回值

pandas.DataFrame；按 time_start 排序，空结果保留列结构。

使用注意

hits = accessor.get_hits(peak_id=919)
print(hits[["merged_index", "hit_index", "dt_start_to_start_ns"]])

get_channels

python
(self, peak_id: int, include_waveforms: bool = False, pad: int = 30) -> list[dict]

返回一个 peak 的逐逻辑通道特征；设置 include_waveforms=True 时，为每项附加完整逻辑通道波形。

参数

数据表
参数说明
peak_id目标 peak 的整数 ID。
include_waveforms为 True 时加载并附加波形字段。
pad波形窗口两侧额外保留的采样点数。

返回值

list[dict]；每项始终包含完整规范特征字段。启用波形后额外包含 waveform、time_ns、abs_time_ps、dt 和 segments。

使用注意

  • 空 peak 返回空列表。
  • 通道键始终按 (board, channel) 解释。
  • 缺少或不完整的 peaklet_channels 会抛出 PeakChannelDataUnavailableError，不会使用 fallback。
  • 一个逻辑通道的全部 merged_indices 会按绝对时间合并为波形片段。

示例

python
channels = accessor.get_channels(peak_id=919, include_waveforms=True)
for channel in channels:
    print(channel["board"], channel["channel"], channel["area"])

plot

python
(self, peak_id: int, view: str = 'stacked', pad: int = 30, figsize: tuple[float, float] | None = None, channel_filter=None, show_sum: bool = True, show_features: list[str] | None = None, show_hit_windows: bool = True, show_merged_index: bool = True) -> tuple[typing.Any | None, numpy.ndarray | None]

唯一的绘图入口：通过 view 选择逐通道总览、通道叠加或求和对照。

参数

数据表
参数说明
peak_id目标 peak 的整数 ID。
viewstacked、overlay 或 sum-comparison。
pad通道波形窗口的边界扩展采样点数。
figsizeMatplotlib 图尺寸；None 使用视图默认布局。
channel_filter仅 overlay 视图使用的通道筛选函数。
show_sum仅 stacked 视图使用；是否显示求和波形。
show_features仅 stacked 视图使用；要标注的特征名称列表。
show_hit_windows仅 stacked 视图使用；是否显示 hit 窗口。
show_merged_index仅 stacked 视图使用；是否标注代表 merged index。

返回值

(figure, axes)；overlay 视图也将单个轴包装为一元素 NumPy 数组。

使用注意

  • 需要安装 Matplotlib。
  • sum-comparison 用于对照两种波形构建路径，不应用作逐采样点相等性检验。
  • 批量保存请在调用方显式循环 plot()、保存并关闭 figure。

示例

python
# 逐通道查看，并标注常用特征
fig, axes = accessor.plot(
    peak_id=919,
    view="stacked",
    show_features=["area", "height", "width"],
)

# 只叠加 board 0 的通道
fig, axes = accessor.plot(
    peak_id=919,
    view="overlay",
    channel_filter=lambda channel: channel["board"] == 0,
)

# 对照框架求和波形与各通道叠加
fig, axes = accessor.plot(peak_id=919, view="sum-comparison")
