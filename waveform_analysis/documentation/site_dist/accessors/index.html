Accessor 接口

从稳定数据产物中进行可审计的查询、筛选与波形访问。

Accessor 接口

Accessor 是只读查询与组合层：它消费正式插件产物，回答跨产物关联、筛选、追溯和波形访问问题，但不重新执行算法，也不创建新的缓存契约。

按问题选择入口

Query Accessor

PeakChannelAccessor

`peak_id`

一个 peak 包含哪些 threshold hits 和通道？它们的特征与波形是什么？

peak 内部排查：查询 hit 时间关系，再查看逐通道面积、高度、占比与波形。查看完整接口 Query Accessor

S1S2PairAccessor

`source` + `mask()` 组合筛选

哪些 S1/S2 配对被选中？它们的波形和位置是什么？

事件级分析：按漂移时间、面积比、标志位筛选配对并读取波形。查看完整接口 Records-backed Accessor

RecordsView

`record_id`

如何按稳定 record_id 读取原始或滤波波形？

records-backed 波形访问：窗口切片、批量填充与信号极性统一处理。查看完整接口

共同约定

01显式 run_id

数据访问始终绑定运行标识，不依赖隐式当前运行。

02只读与按需加载

复用正式产物，仅在查询需要时读取较大的波形层。

03稳定标识

record 使用 record_id；硬件通道使用 (board, channel)。
