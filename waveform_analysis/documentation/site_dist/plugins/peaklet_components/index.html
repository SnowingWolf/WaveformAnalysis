Return flat peaklet-to-hit_merged membership rows.

依赖

默认画像：declared。

数据表
依赖版本约束解析方式必需字段说明
hit_merged-declared-Merge nearby threshold hits per channel with time-gap and max-width constraints.

工作方式

  1. Return flat peaklet-to-hit_merged membership rows.

配置

数据表
名称类型默认值单位跟踪弃用说明
time_window_nsfloat100.0-是否跨通道 peaklet 合并时间窗口
max_total_width_nsfloat10000.0-是否peaklet 最大总宽度
dtintNone-是否保留兼容配置；优先使用输入 hit_merged 的 dt

输出

structured_array output with fields: peak_id, merged_index.

数据表
字段DType单位含义
peak_idint64NonePeaklet identifier, matching the row index in the peaklets table
merged_indexint64NoneIndex of the hit_merged row belonging to this peaklet

使用

python
from waveform_analysis import Context
from waveform_analysis.plugins import profiles

ctx = Context(config={"data_root": "DAQ", "daq_adapter": "vx2730"})
ctx.register(*profiles.cpu_default())
result = ctx.get_data("run_001", "peaklet_components")

失败模式

  • 任一声明依赖（hit_merged）缺失或字段不符合输入契约时，执行会失败。
  • 配置校验或输出 schema 校验失败时，结果不会被视为有效插件产物。
