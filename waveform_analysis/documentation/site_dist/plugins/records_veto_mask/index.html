records_veto_mask

RecordsVetoMaskPlugin

v0.1.0staticarray
recordsrecords_veto_mask

Bool mask for veto-channel records after channel-role splitting.

配置

records_veto_mask 配置
参数默认值说明
channel_configNone按 (board, channel) 的通道角色配置；role='detector' 进入正常 hit，role='veto' 仅作为 veto 通道保留。

输出字段

records_veto_mask 输出字段
字段名类型单位说明
valueboolNoneBoolean veto mask, one entry per `records` row: True marks a record that belongs to a veto channel (role='veto' in channel_config) and passed the waveform asymmetry selection, so it should be excluded from normal detector hit finding.

快速使用

python
from waveform_analysis import Context
from waveform_analysis.plugins import profiles

ctx = Context(config={"data_root": "DAQ", "daq_adapter": "vx2730"})
ctx.register(*profiles.cpu_default())
result = ctx.get_data("run_001", "records_veto_mask")
