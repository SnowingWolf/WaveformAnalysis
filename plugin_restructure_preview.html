设计要点

  • 平铺 per-plugin：每个 provides 一个目录，含 plugin.py（类实现）、__init__.py（新代码唯一 import 面）、manifest.yaml（声明）、SKILL.md（agent 叙事，生成器产出）、requirements.txt（第三方依赖）、tests/（随插件测试）。
  • 向后兼容：cpu/、streaming/ 退化为纯 shim 壳；hit/、peaks/ 因 provides 同名冲突升级为 bundle，同时承载旧家族 shim 模块（hit_merge.py、peaklets.py 等保留原路径，旧深导入继续可用）。
  • 算法属主：多插件共享计算由「属主 bundle」的 _compute.py 持有，兄弟 bundle 单向依赖（hit_merged ← hit_merge_clusters/hit_merged_components；peaklets ← 其余 5 个；records ← wave_pool*；records_detector_mask ← records_veto_mask）。
  • shared/ 库：_dt_compat/_record_utils/_wave_source 上提为跨插件通用库。
  • 依赖三分：manifest.yaml 区分 depends_on（数据依赖）/ third_party_dependencies（第三方 Python 包）/ plugin_dependencies（跨 bundle 代码耦合）。
  • 删除 accelerator：装饰性文档字段（36 插件中 35 cpu / 1 streaming / 0 jax，区分度近零），从生成器/模板/测试移除；保留运行时相关的 output_kind/supports_streaming/supports_gpu。
  • 双副本：RawFileNamesPlugin 在 cpu/raw_files.py 与 cpu/waveforms.py 各定义一份（plugin_sets/io.py 与 cpu/__init__.py 用不同副本），重构时合并到 raw_files/ bundle。
